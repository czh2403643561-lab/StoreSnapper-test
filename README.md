# StoreSnapper

可逐步扩展的 Chrome 插件，采用共享 StoreSnapper 工作台承载 Temu 图片找货和 TikTok Shop 商品管理采集。

## 工作台

- 点击浏览器工具栏的 StoreSnapper 图标可打开页面菜单；右侧工作台统一提供“工作台、Temu 找货、TikTok 采集、导出中心、运行日志、设置”导航。页面入口按平台和实际页面内容识别。
- Temu 找货在未搜索时默认收起主面板，保留窄导航条以避免遮挡商品；点击商品图上的放大镜后展开货源栏。TikTok 采集继续使用原有采集会话、人工确认翻页及恢复流程。
- 导出中心从本机扩展存储读取已有的非空 TikTok 采集会话，可单独导出；运行日志聚合实际搜图事件、图片诊断和 TikTok 采集日志。
- 设置提供可保存的“记住上次页面”和“紧凑显示”。品牌图标来自项目交接包中的透明资源，并生成扩展图标尺寸。

## 当前功能

- **Temu 找货：**在 Temu 首页、推荐／闪购、类目和搜索列表的商品卡片上悬停主图，以主图搜索 1688 相似货源；不开发商品详情页搜图。右侧货源栏可收起、展开和关闭；顶部品牌栏可拖动工作台，关闭后可拖动入口，位置会记住。
- **TikTok 采集：**仅在 Seller Center 商品管理页显示右侧采集入口。采集当前筛选下的一页商品，按商品 ID 去重，区分商品主行和 SKU 展开行；滚动后核对页数、数量和关键字段。只有点击“采集下一页”才会翻页；翻页刷新后会恢复采集面板的展开／收起状态。
- TikTok 采集记录保存在本机扩展存储中，可恢复、重新检查并随时导出 JSON；未完成或待检查的数据会明确标注，不上传到外部服务。

## 范围和数据说明

- TikTok 模式不支持商品详情页，不自动连续翻页，不采集完整 SKU 明细，也不执行 AI 分析。
- TikTok 商品 ID、标题、主图、状态、价格、库存、销售表现及页面可读时的 SKU 数量均来自页面实际显示内容；无法读取的字段会留空并列入 `missing_fields`。
- 图片找货返回的是相似货源，不代表完全同款、价格有效或库存已确认；需要在 1688 核实。
- 插件不保存账号凭据、Cookie，不处理登录或安全验证。

## 安装和更新

1. 在 Chrome 打开 `chrome://extensions` 并启用“开发者模式”。
2. 选择“加载已解压的扩展程序”，选中本仓库的 `extension` 文件夹。
3. 更新代码后，在扩展管理页点“重新加载”，再刷新目标页面。

## 手动验收

- **Temu：**在首页／闪购、类目和搜索列表分别打开工具栏菜单，检查平台识别；悬停商品卡片主图时应立即出现放大镜。点击后验证真实 1688 搜索、结果切换和侧栏操作。
- **TikTok：**在已登录的 Seller Center 打开商品管理页，点右侧“商品采集”，开始采集本页；完整性通过后手动点“采集下一页”，最后导出 JSON。状态为“待检查”时，先处理页面未加载或缺字段，再点“重新检查本页”。
- **工作台：**在任一受支持页面切换六个导航入口；悬停顶部品牌栏（收起时悬停导航栏品牌图标）应显示可抓取光标，拖动后刷新页面应保留位置；关闭后可拖动浮动入口。检查导出中心只列出已有记录、日志可查看和复制、设置在刷新后保持。
- 真实 TikTok 商家页尚未由自动化环境验证，最终以用户普通 Chrome 中的实际页面为准。
