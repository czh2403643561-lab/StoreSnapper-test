# StoreSnapper

StoreSnapper 是一款可逐步扩展的 Chrome 插件，按当前标签页自动识别功能：Temu 商品列表和 1688 商品浏览页可用主图找 1688 相似货源，TikTok Shop Seller Center 商品管理页可按导入的商品 ID 清单勾选商品。

## 使用方式

- 点击 Temu 商品主图上的放大镜后，货源结果显示在 Chrome 右侧原生侧栏；工具栏菜单也能打开 Muse 批量图搜页，不需要另装一个插件。
- 在 1688 首页或商品浏览页悬停商品图片，也可点击放大镜直接验证同一搜图链路，结果显示在右侧侧栏。
- 1688 商品详情页采集面板支持拖动并记住位置；0.4.20 / schema 5 只导出 Muse 使用的标题、规格/单价/重量、单份包裹信息、白名单属性及完整图片。ZIP 附有顺序、路径、MD5 和去重信息；warnings 仅报告图片失败、SKU 图缺失和商品级包裹字段缺失。采集面板齿轮可单独设置导出到本机下载或指定本机文件夹；文件夹权限失效时会显示恢复入口，不影响插件其他模式。三商品回归待用户重导验收，进度见 [项目状态](PROJECT_STATUS.md)。
- TikTok Seller Center 商品管理页只显示一条“采集索引 → 导入商品 ID 清单 → 勾选当前页”流程。沿用原有逐页滚动采集和本地记录；已有完整采集结果可直接复用，不再单独建立第二份索引。索引只以商品 ID 和数量判定完整，主图或其他商品字段不影响勾选。
- 清单支持含“商品ID”列的 XLSX/CSV，并提供纯文本列 XLSX 模板。索引可用时导入后自动核对并勾选当前页，每轮最多新增勾选 30 件；插件不执行下架、删除或确认。此功能待用户在真实登录页面验收。
- Temu 仅支持首页、推荐／闪购、类目和搜索商品列表，不支持详情页。货源为相似商品，不代表完全同款、价格有效或库存已确认；缺失字段不会补造。
- 设置中的“紧凑货源卡片”会改变右侧侧栏的商品卡片尺寸。日志默认放在工具栏菜单内，图片诊断不记录图片内容、登录信息或 Cookie。
- Muse 批量图搜页支持选择或拖入 CSV/XLSX、逐条搜图和断点续跑；CSV、JSON、缩略图 HTML 可分别下载，也可一键打包下载 ZIP。批量页的结果保存在本插件的本地存储，详细输入输出规则见 [Muse 说明](muse-edition/README.md)。

## 安装

1. 在 Chrome 打开 `chrome://extensions` 并启用“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择仓库中的 `extension` 文件夹。
3. 更新后在扩展管理页重新加载 StoreSnapper，再刷新目标网页。

此前若安装了独立的 Muse 版，先从旧版导出已完成批次，再使用主插件的批量入口。Chrome 不会在两个扩展之间自动迁移本地批次数据。

右侧侧栏由 Chrome 原生 Side Panel API 提供，需 Chrome 116 或更新版本。侧栏具体宽度与左右位置由 Chrome 控制，插件会按实际可用宽度排版。

## 1688 ZIP 保存到指定本机文件夹

此设置只作用于 1688 商品采集面板。点面板齿轮，点“选择或更改文件夹”，在打开的页面点“选择本机文件夹”，选电脑上的目标文件夹；如果这里选择的是 Google Drive for Desktop 同步文件夹，插件会把 ZIP 写到本机目录，之后由 Google Drive 自己同步。无需 Google OAuth、Google Cloud 项目或云端 API。

“导出位置”可在“本机下载”和“指定本机文件夹”之间切换。浏览器可能在重启后要求重新确认文件夹访问权限，可从同一设置页面恢复。插件只保存用户明确选择的目录授权，不读取目录中现有文件内容；ZIP 仍只由 1688 商品采集生成。

## 手动验收

- **1688：**在已登录的 1688 首页或商品浏览页悬停商品图片并点击放大镜；右侧应出现加载状态和相似货源。独立测试浏览器已实测两次搜图均返回 60 个货源。
- **Temu：**在商品列表中悬停主图并点击放大镜；右侧应出现加载状态和 1688 相似货源。令牌先通过扩展 Cookie 接口读取，读不到时沿用旧版的 1688 页面 Cookie 读取方式。Temu 当前因测试账号无法登录，页面入口仍待真实验收。
- **TikTok：**在 Seller Center 商品管理页打开右侧面板。若已有完整采集结果，应显示“可复用已有索引”；否则采集当前页并逐页继续。导入清单后，先用一件商品验证当前页勾选，再小批量继续；下架由用户手动执行。
- 工具栏菜单中的“设置”可切换紧凑卡片，“运行日志”可复制；“导出与诊断”只有存在数据时才启用相应导出按钮。
- **批量图搜：**从工具栏菜单打开批量页，拖入或选择同一个 CSV；导入后应显示相同条数。点击“打包下载 ZIP”，压缩包内应包含与三个单独导出按钮相同的 CSV、JSON、HTML。
- **1688 详情采集：**重载扩展后重导 `1098266654765`、`591770681285`、`783937409751`。核对 schema 5 的字段白名单、SKU 组合/价格/重量、商品级包裹尺寸、规格一图片映射、`image_order.json` 的顺序与 MD5，以及 warnings 只出现三类允许项。
- **1688 指定文件夹导出：**在采集面板设置中选一个测试文件夹，导出一个商品；确认 ZIP 直接出现在该目录，再切回“本机下载”确认原下载方式仍正常。若目标是 Google Drive 同步目录，再确认 Drive for Desktop 后续完成同步。
