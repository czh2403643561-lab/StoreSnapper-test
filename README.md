# StoreSnapper

- 项目是什么：可逐步扩展的 Chrome 插件，首期在 Temu 商品列表页用主图搜索 1688 相似货源。
- 解决的需求：把 Temu 分类和搜索列表中的商品图片快速用于 1688 找货。
- 核心功能：悬停搜图、持久的左侧货源栏、紧凑的多商品结果卡和 1688 商品详情跳转。
- 第一阶段：只支持 Temu 分类页与搜索结果页；搜索结果为相似货源，款式、价格和库存需在 1688 核实。
- 安装：无需构建；在 Chrome 打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，并选中本仓库的 `extension` 文件夹。
- 手动验收：同一 Chrome 登录 1688 并保留一个 1688 页面；打开 Temu 分类或搜索列表，悬停商品主图并点放大镜。左侧货源栏应显示真实的相似结果，可收起、展开、关闭；切换商品后结果应更新，点击卡片会打开 1688 商品页。
- 数据说明：搜索结果只是图片相似商品，需在 1688 核实商品、价格、起批量与库存；接口返回缺字段时显示“暂无”。插件不保存登录信息，不提交未登录图片，也不处理登录、验证码或安全验证。
- 检查：运行 `node --test tests/core.test.mjs`。
