# StoreSnapper

StoreSnapper 是一款可逐步扩展的 Chrome 插件，按当前标签页自动识别功能：Temu 商品列表用主图找 1688 相似货源，TikTok Shop Seller Center 商品管理页采集商品数据。

## 使用方式

- 点击 Temu 商品主图上的放大镜后，货源结果显示在 Chrome 右侧原生侧栏；工具栏点击打开的是设置、导出、运行日志和关于信息，不需要手动切换平台。
- TikTok Seller Center 商品管理页识别成功后，在右侧侧栏操作商品采集。紧凑统计和两列操作减少界面占用；当前页结束后，只有手动点击“采集下一页”才翻页，原采集记录、恢复和 JSON 格式继续保存在本机。
- Temu 仅支持首页、推荐／闪购、类目和搜索商品列表，不支持详情页。货源为相似商品，不代表完全同款、价格有效或库存已确认；缺失字段不会补造。
- 设置中的“紧凑货源卡片”会改变右侧侧栏的商品卡片尺寸。日志默认放在工具栏菜单内，图片诊断不记录图片内容、登录信息或 Cookie。

## 安装

1. 在 Chrome 打开 `chrome://extensions` 并启用“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择仓库中的 `extension` 文件夹。
3. 更新后在扩展管理页重新加载 StoreSnapper，再刷新目标网页。

右侧侧栏由 Chrome 原生 Side Panel API 提供，需 Chrome 116 或更新版本。侧栏具体宽度与左右位置由 Chrome 控制，插件会按实际可用宽度排版。

## 手动验收

- **Temu：**在普通 Chrome 已登录的商品列表中悬停主图并点击放大镜；右侧应出现加载状态和 1688 相似货源。缺少搜图凭据时插件会先向 1688 初始化再继续；若仍需登录，可在侧栏打开 1688 页面，待侧栏显示“已取得搜图凭据”后返回原 Temu 标签页重新点击放大镜。真实登录与搜图由用户手动验收。
- **TikTok：**在 Seller Center 商品管理页点浏览器工具栏图标，打开当前页面的右侧功能面板；开始采集后可刷新页面和人工翻页，面板应保留并更新任务状态。导出 JSON 并核对页码和商品 ID。
- 工具栏菜单中的“设置”可切换紧凑卡片，“运行日志”可复制；“导出与诊断”只有存在数据时才启用相应导出按钮。
